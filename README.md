# Procedural Showroom

Orbit **cars and guns** rebuilt as procedural Three.js models from studio reference images.

## Stack

- Vite + TypeScript + Three.js
- Deploy target: **Vercel**

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

1. Push this repo to GitHub
2. Import the project in [Vercel](https://vercel.com/new)
3. Framework preset: Vite (or leave defaults — `vercel.json` is already set)
4. Deploy

Live model so far:

- **Toyota Trail SUV** — `#/demo/toyota-suv`

Coming soon slots are ready for the next car and gun references.
